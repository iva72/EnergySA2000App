# Energy SA-2000 App

## Как использовать
1. Зарегистрируйся на https://github.com и создай репозиторий `EnergySA2000App`.
2. Загрузите все файлы проекта в репозиторий.
3. На телефоне открой репозиторий и скачай ZIP через "Code → Download ZIP".
4. Распакуй ZIP и загрузите проект на EAS Build: https://expo.dev/eas
5. Выбери Android APK и собери приложение.
6. Установи APK на Android 16+ и тестируй работу с колонкой.
